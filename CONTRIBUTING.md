# Contributing to Study Manager

Thank you for your interest in contributing to Study Manager!

## How to Contribute

1. Fork this repository.
2. Clone your fork.
3. Create a new branch for your changes.
4. Make your changes.
5. Test your changes locally.
6. Commit your changes.
7. Push your branch.
8. Create a Pull Request.

## Guidelines

- Keep the code simple and readable.
- Follow the existing project structure.
- Test your changes before submitting a Pull Request.
- Write clear commit messages.
- Do not commit passwords, API keys, or other sensitive information.

## Reporting Issues

If you find a bug or have a feature suggestion, create an Issue on GitHub and clearly describe the problem or idea.

Thank you for contributing!
